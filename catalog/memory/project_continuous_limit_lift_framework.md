## The single-Cardan baseline (non-equivariance Δω)

Model input/output shaft rotations as elements of SO(3). The input shaft rotation around the z-axis = one-parameter subgroup generated by Xᵤ ∈ 𝔰𝔬(3). When bent by articulation angle β, the shaft undergoes a fixed spatial rotation R_y(β) ∈ SO(3).

For a single standard Cardan joint, the output rotation Φ(θ) is governed by:

```
tan(θ_out) = cos(β) · tan(θ_in)
```

In Lie-group terms: input progresses along smooth vector field V_in = ω·Xᵤ; output V_out is modulated by a time-varying pullback. The **non-equivariance error**:

```
Δω = ω_out - ω_in = ω_in · ( cos(β) / (1 - sin²(β)·cos²(θ_in)) - 1 )
```

This velocity fluctuation means a single universal joint **fails to generate a commutative diagram under the action of the circle group S¹** — the mapping does not commute with the time-translation operator.
