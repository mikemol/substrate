When a handoff brief hands a build + a **load-bearing flag** ("verify this, don't inherit it"), the flag names where the AUTHOR thinks the risk is. The decorrelation-oracle value is catching the risk they FRAMED PAST. The move: before deep-reading or building, run the **cheapest structural falsifier** — usually **one level BELOW the flagged axis**: *is the representation a faithful section of the source?* (does `lower` lose nothing the build needs to invert?). A representation that silently drops residue obstructs the build UPSTREAM of the flagged risk, so testing the flag directly never reaches it.

**The instance (Ⓤ, jea IR→Python unparser, 2026-06-19):** brief flagged "byte-grade round-trip idempotence — canonical-extrude clean vs arbitrary-extrude *wanders*; measure it." That framing is an either/or on the WRONG axis. A 10-line probe (lower `y = self.foo + bar.baz(1)`, dump the interned IR) showed `ast.Attribute.attr` and `alias.name` are **dropped — neither in the canonical `key` nor the residue `payload`** (the generic lowering walks only AST *node* children; `str` fields fall through). So `a.foo` and `a.bar` **intern to the same node** (a false-duplicate, the exact class the Lowerer's own comment says it fixed for free Names — Attribute never got it). Byte-grade round-trip is therefore **impossible** on real jea source (attr names unreconstructable), not "wander" — upstream of idempotence, and the canonical identity is *wrong*. Caught in minutes, before building the (large, doomed) unparser.

**The recurring shape (sibling of [[feedback_module_boundary_dissolves_blowup]]):** twice now the real question was **WHAT is preserved/captured**, not **HOW it computes/converges** — module-boundary opacity (what transits) and representation faithfulness (what's captured). When a framing about *how* doesn't hold, recurse to the *what* one level down.

**How to apply:** on a build-from-brief, first ask "is the representation this build inverts/uses a faithful section?" and write the cheapest probe that would falsify it. Lead with the verified finding + the computed partition (FIXED=key / RESIDUE=payload / **HOLE**=dropped residue that must move into the key if referential). Don't silently change the author's representation — surface the mis-cut + the principled fix (referential string-fields belong in the KEY, like free names) and let them re-cut. Verify, don't inherit; the cheapest verification is a section check.

**RESOLVED → Ⓤ-fix (be4bf8a, pushed):** the user dispatched the fix. The HOLE was 5 node classes, not 1 — `Attribute.attr`/`alias.name`/`keyword.arg`/`ImportFrom.module`/`Global|Nonlocal.names` all fell through the same generic `iter_child_nodes` walk (str fields aren't node children). Fixed the whole orbit by COPYING the free-Name treatment (referential → `op`/key) across all five rows + the cst Attribute mirror. Regression-checked the DUAL risk: the fix must not OVER-distinguish — confirmed alpha-equivalence preserved (a renamed *bound* receiver still quotients; only the referential `.attr` distinguishes). That bound-quotient / referential-key line IS the Ⓖ★ idempotent-vs-invertible genus.

**The generalization worth carrying (the recursive common structure of ALL three handoff flags):** "does the byte round-trip converge?", "does the trace-fixpoint close?", "is the rewrite a group action?" are ONE either/or — **is the residue retained or discarded** — = the Ⓖ★ genus. Retain ⟹ invertible/group species ⟹ converges to the orbital *identity*. Discard ⟹ collapsing/idempotent species ⟹ converges (if at all) to a *projection* (a coarser quotient), never the identity. So a "will it converge / is it decided" flag is answerable STRUCTURALLY (which species is this operation in?) before the empirical build — and the fix for a "won't converge" is always "move it from the collapsing to the invertible species by retaining the residue." Sibling of [[feedback_never_discard_residue]] and [[feedback_duality_operator_is_either_or_trap]]; the unifying lens for [[feedback_module_boundary_dissolves_blowup]]-class flags.
