User instruction (2026-07-16, ⟡set1-ra-internallogic): "When you see things like [a scope hedge you don't plan
to pursue immediately], record an observation (w/ context and provenance) somewhere so it can be picked up later."

**The rule:** every time I write or think a SCOPE HEDGE — "this would be a genuine sub-arc", "deferred", "out of
scope", "not pursuing now", "a separate arc", "future work", "the remaining obligation" — that hedge is a DEFERRED
OBSERVATION, and it must land in a durable, pick-up-able place (the plan file's ⟡ next-steps index, a scratch
observations note, or a `defer`/catalogue entry), tagged with:
- **context** — what the deferred thing IS, concretely enough to resume (the actual missing lemmas/defs, not "more work");
- **provenance** — WHICH arc/decision spawned it + the date, so its origin is recoverable.

**Why:** a deferral is [[never-discard-residue]] applied to SCOPE. An un-recorded hedge evaporates — the next
session (or the next me, post-compaction) re-derives it from scratch or, worse, never picks it up. Labeling it
(a ⟡ symbol) makes it unambiguously specifiable. This is the same discipline as the negative-findings corpus:
the thing you're NOT doing is data, kept with its reason, not deleted.

**Caveat — verify the hedge before recording it as a wall.** A scope hedge is often the declaring-a-wall reflex
([[declaring-wall-rebuild-reflex]], [[reuse-search-before-feasibility-conclusions]]): ⟡set1-ra-internallogic's
own hedge "the real Heyting connectives ∩/∪/⇒/¬ would be a genuine sub-arc" was DISPROVEN by actually probing it
(they were cheap 3-line mirrors of `max-Sieve` + one assoc-transport; built + gate-green same session). So: probe
the hedge first (is it really deferred, or is it a wall-reflex on something cheap?); record what SURVIVES the
probe (here: only the Heyting AXIOMS remained deferred, not the connectives), with its context + provenance.

Relates to [[never-discard-residue]], [[declaring-wall-rebuild-reflex]], [[reuse-search-before-feasibility-conclusions]],
[[open-threads]], and the construct-dont-classify "classify-FIRST for genuine forks" caveat.
