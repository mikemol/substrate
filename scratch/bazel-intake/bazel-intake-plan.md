## The result: audit-as-warrants, not the migration

The migration question was not the interesting one. All four repos already share the verdict engine by ADOPTION — paperkit to linux-sources to cassian — so its recurrence corroborates nothing, and what the corpus actually establishes is methodological [@res-not-migration]; and from that, Audit-as-warrants beats audit-as-prose: a claim carrying a source-anchored check goes red the moment its needle is edited out of the source, so prose cannot outlive its sources [@res-warrants]; so Two of the three comparison syntheses convict themselves of the defect they name: linux-sources closes by calling its own document ungated prose [@res-self-convict]; Substrate's own ledger already measures the gap the warrants discipline closes: its kind census reports the `standing` majority as vacuous, passing unconditionally, against a behavioural minority [@res-standing-vacuous]; a traces needle proves PRESENCE, not CURRENCY: a document that supersedes itself internally defeats the check while staying green, because a string is not a position in an argument [@res-presence-not-currency]; and from that, the needle and the corpus stamp answer different questions about one event — did the source change, and did my claim survive — so a repo running either alone has half the coverage and no signal that it has half [@res-two-instruments].

## What substrate adopts, and from whom

Records-as-deps ranks first: a check's verdict becomes a declared build artifact and therefore an action input, so memoization, invalidation and parallelism come from the build system instead of a bespoke cache [@ado-records-as-deps]; `resource_set` is a scheduling hint that bounds nothing — bazel schedules, a cgroup bounds — so membudget remains substrate's only enforcement layer under bazel rather than becoming redundant [@ado-resource-set]; and from that, Materialise, do not point: paperkit's relative-path rung followed a symlink into the live working tree, so a sandboxed action imported unstaged sources — a sandbox escape that passes [@ado-materialise]; so the three-tier ladder is directly instantiable: sandbox is hermetic and cached, toolchain is cacheable and host-env, and local is uncached and always re-runs — the sound placement for an action reading unpinnable live state [@ado-tier-ladder]; and from that, the toolchain tier is adopted with care: its category is principled but a cached verdict keyed on an incomplete fingerprint is a stale green, so a fingerprint must be derived from the invocations or the tier must not cache [@ado-fingerprint]; so Path-independent caching is the adoption whose value is highest DURING a migration evaluation, because the evaluation is what produces a second checkout — and the default action cache is keyed on the workspace path, so two worktrees share nothing [@ado-path-independent].

## What substrate provides, measured

Substrate is already a source to the ecosystem rather than only a consumer: cassian vendors substrate's shape and correctness hooks as real committed files [@pro-vendored-hooks]; and from that, a second peer vendors substrate code independently: paperkit holds adopted copies of bibstruct, edit_snapshot and vfs, with ownership recorded as substrate's [@pro-vendored-tools]; so a decline that names its own reversal scale is worth more than an adoption: paperkit refused substrate's feedback-arc-set solver as correct-but-unused on an 8-node graph while stating that the calculus inverts at substrate's scale [@pro-decline].

## What the corpus exposed in substrate

A measured-false claim ships in every generated BUILD file: bazel_emit's unresolved block asserts that membudget and bazel together would double-bound, which the corpus refutes since bazel bounds nothing [@fix-double-bound]; the intake instrument is blind to part of the corpus: mdstruct's AST modes return nothing on one audited peer document while its byte-level modes read the same file, so a reuse-search over it would report confident false absences [@fix-mdstruct-blind]; and from that, Substrate has no census of built-but-uninvoked capability across its invocation surfaces, and would score badly on one: bazel_emit is invoked by nothing and make_emit is called by no build [@fix-unwired]; so Paperkit's do-not-adopt list names a defect substrate shares: hand-maintained enumerations of things the system already computes, where adding a guard over the enumeration reproduces the problem one level up [@fix-enumerations]; and from that, a substrate framing was refuted by measurement and is owed acknowledgement: substrate explained a peer defect as surviving because the file sat off the enforcement path, when the file is in the linter's argument list and the real cause is a blind predicate [@fix-witness-refuted]; so the recurrence of one defect class across independent auditors is evidence it is structural rather than carelessness, so the repair belongs in the type rather than in remembering [@fix-structural-class]; and from that, Substrate has two enumerations of its own corpus with no common owner — git's ignore and the suite walker's skip list — so gitignoring the build tree removed it from git's view while the walker still admits it, and the suite roster counts every package module twice [@fix-two-enumerations]; so Substrate has already paid for the undeclared-input class the peers describe: an interpreter mismatch under uv meant a type census ran, failed, parsed no error lines, and banked zero keys as clean [@fix-uv-false-green].

## Inheritance is not corroboration

Shared structure arrived at by adoption carries no corroborative weight, and independent arrival is only visible once the lineage is subtracted [@lin-inheritance]; and from that, the two syntheses appeared to disagree — cassian reading independent convergence as the real signal, paperkit warning that inheritance is not convergence — but cassian conceded the point in the same document, so the split is settled across the corpus rather than contested [@lin-convergence]; so One principle carries four names across the ecosystem — mechanize the caveat, do not narrate it — and substrate already holds it as bounds-in-band, printing a reader's blind spots in its own output [@lin-caveat].

## What this plan does not establish

A traces check proves a claim is recorded where cited, never that the mechanism is globally true — so every peer-corpus claim here witnesses what a peer SAID and not that they are correct [@bnd-said-not-true]; and from that, Nothing in substrate's bazel work has been built: there is no workspace, no bazel in the checkout, and the rule the emitter calls does not exist, so whether the emitted text builds the tree is unmeasured [@bnd-unbuilt]; so the corpus moved under this reading at least once, so every finding is stamped against specific bytes and a drifted artifact unstamps only the findings that cite it [@bnd-corpus-moves].
