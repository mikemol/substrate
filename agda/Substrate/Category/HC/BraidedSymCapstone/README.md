# BraidedSymCapstone — Substrate.Category.HC.BraidedSymCapstone

A capstone is a **directory with a README**, not a module. It ATTESTS a
roster; it does not import one. The former `BraidedSymCapstone.agda` was a pure barrel —
prose and imports, no definitions of its own — so the attestation is prose
and the roster is a table. A consumer that wants one of these names binds
it at its OWNER, directly.

Substrate.Category.HC.BraidedSymCapstone

HC20 — Braided/Symmetric sub-arc capstone (HC11-HC20).

Each UP names a distinguished object in UPCategory; the
substrate's universal-property catalogue now includes the
canonical braided + symmetric + cartesian-monoidal + Drinfeld-
center landmarks.
