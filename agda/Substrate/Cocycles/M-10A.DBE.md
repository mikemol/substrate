## Step 1 — Halt and name the target

Build a structural F₂-linear shadow `Codeword-Structural = Vector 5`
plus the F₂-linear reading of `IsReserved` (as kernel of the
high-two-bits projection), with universal-property bridges to the
existing `Bool⁵`-based `Codeword` and `IsReserved` predicate from
[Substrate/Cocycles/V4Signature/Codeword.agda](Substrate/Cocycles/V4Signature/Codeword.agda).

**In scope:**
- `Codeword-Structural = Vector 5`
- `Reserved-Selector : Linear 5 2` (the high-two-bits projection)
- `Reserved-Structural = KernelCode 5 2` (its kernel)
- Bridges: `Codeword ↔ Vector 5` and `IsReserved ↔ Reserved-Structural-Membership`

**Out of scope (deferred to M-10B/M-10C):**
- `Live` as the kernel's complement (Live is 24 elements, not an
  F₂-subspace — it doesn't fit the KernelCode/ImageCode shape).
- Full Live ⊎ Reserved disjoint-union bridge to S₄ ⊎ (Axis × F₂).
- The unification proving the ambient's two readings (codeword
  bit-form vs. Live ⊎ Reserved structural form) agree.

The existing `Codeword.agda` already commits to the
multi-reading-ambient discipline: the predicate IS the load-bearing
piece, all readings are derived. M-10A adds an F₂-linear reading
that joins the existing ones (Axis × Bool, S₄) without privileging
any single form.

## Step 2 — Search for repeatable form

The shared substructure across the whole bridge:

| Layer | Bool⁵ form | F₂-linear form | Bridge mechanism |
|-------|-----------|----------------|------------------|
| Per-bit | `Bool` | `F₂` | M-1.5 `F₂-Like` instance + iso |
| Tuple | `Bool × Bool × ...` | `Vec F₂ 5` | Componentwise extension of per-bit |
| Predicate | `IsReserved cw : Set` | `In-Kernel Reserved-Selector v` | Definitional equivalence after bridge |
| Decomposition | `Reserved ↔ Axis × Bool` | `Reserved-Structural ↔ Vector 3` | Linear iso between the kernel and its natural basis |

Repeatable form: **componentwise bit-bridge** — any product-of-bits
type bridges to a vector-of-F₂ type, with the per-component
universal property (M-1.5) lifted bitwise.

This is also the SECOND instance of "bare 2-element type ↔ F₂" in
the M-series (the first was M-12 N-4 Chirality ↔ F₂). Per the
shadow-architecture orbit-saturation rule, two instances do not yet
trigger RFS — that's S2G territory (catalogue position, generator is
already M-1.5's `F₂-Like` record). The third instance (if and when
it appears) would license RFS extraction.

## Step 3 — Name the costructure (shadows)

Numbered N-x within this slice; each lives in its own file per
externalisation discipline.

**N-1 — `Bool-is-F₂-Like`**: instantiate `F₂-Like` for `Bool`,
  deriving the canonical `Bool ↔ F₂` iso via M-1.5's universal-
  property bridge (no manual case enumeration).

  File: `Substrate/Algebra/F2/FromBool.agda`.

  Convention: `false ↔ 𝟘`, `true ↔ 𝟙`. Matches the M-12 N-4
  Chirality convention (`even ↔ 𝟘`, `odd ↔ 𝟙`) and the catalog's
  bit-encoding semantics.

**N-2 — `Bool⁵ ↔ Vector 5` bridge**: lift N-1 componentwise to the
  whole Codeword type. Bundles as a `Foundations.Bijection`.

  Two angles considered (per DBE Step 6 multi-angle reserve):

  - **Angle A — five-tuple destructuring** (`λ (b₀, b₁, b₂, b₃, b₄)
    → bool→F₂ b₀ ∷ ... ∷ []`). Explicit, computes by definition.
  - **Angle B — generic `Bool-product-k ↔ Vector k` combinator**
    parameterised over k. More reusable but requires a tuple-of-k
    representation that doesn't match Codeword's nested `_×_` shape.

  **Chosen: Angle A.** The five-tuple shape is fixed by
  Codeword.agda's existing definition; matching it explicitly keeps
  the bridge mechanical and round-trips definitional.

  File: `Substrate/Cocycles/V4Signature/Codeword/Structural.agda`
  (the bridge layer).

**N-3 — `Reserved-Selector : Linear 5 2`**: the F₂-linear projection
  picking out bits 3 and 4 (the high-two-bits the existing
  `IsReserved` predicate tests).

  Built via M-5's `linear-from-images`. Basis-images:
  - `e₀ ↦ 𝟎ⱽ`, `e₁ ↦ 𝟎ⱽ`, `e₂ ↦ 𝟎ⱽ` (low bits don't contribute)
  - `e₃ ↦ 𝟙 ∷ 𝟘 ∷ []`, `e₄ ↦ 𝟘 ∷ 𝟙 ∷ []` (high bits project)

  File: `Substrate/Cocycles/V4Signature/Codeword/Structural/Selector.agda`.

**N-4 — `Reserved-Structural : KernelCode 5 2`**: the structural form
  of the 8 reserved codewords, as the kernel of N-3.

  Membership = "the high-two-bits-projection vanishes" = the
  high-two-bits are zero, structurally identical to the existing
  `IsReserved` predicate's content.

  File: `Substrate/Cocycles/V4Signature/Codeword/Structural/Reserved.agda`.

**N-5 — `IsReserved ↔ In-Kernel Reserved-Selector` bridge**: the
  predicate-level bridge, asserting that for any codeword `cw`,
  `IsReserved cw ⇔ In-Kernel Reserved-Selector (N-2.to cw)`.

  Both directions case-split on the high-two-bits' Bool values;
  each case closes by `refl` after componentwise F₂ rewriting.

  File: `Substrate/Cocycles/V4Signature/Codeword/Structural/IsReserved.agda`.

**N-6 (optional) — `Reserved-Structural ↔ Vector 3` bridge**:
  identifies the 8-element Reserved-Structural with the low-3-bits
  vector space (Axis encoded in bits 0-1, sign in bit 2). Provides
  the structural analogue of the existing `Reserved ↔ Axis × Bool`
  iso in Codeword.agda.

  Built via a Linear 5 → 3 "drop-high-two" map; restricted to the
  kernel, it's a bijection.

  Deferred to a follow-up if Phase 1 fills out cleanly. The bare
  bijection is `Vector 5 ↾ Reserved-Selector ↔ Vector 3`, which
  rewrites once the M-4.5 Image/Kernel-Equivalent machinery is
  pointed at it. ~50 lines.

  File: `Substrate/Cocycles/V4Signature/Codeword/Structural/ReservedBasis.agda`.

## Step 5 — Name the entailment

**Entailment claim:**

For any `cw : Codeword`, the F₂-linear reading via N-5 is
equivalent to the existing predicate reading via Codeword.agda:

```
IsReserved cw ≡ In-Kernel Reserved-Selector (Bool⁵→Vector5 cw)
```

(read as: the predicate inhabitance set on the LHS is in bijection
with the proof set on the RHS).

**BHK content:** the bridge IS the proof transformer. Given a proof
that `IsReserved cw` (i.e., bit₃ cw ≡ false ∧ bit₄ cw ≡ false), the
bridge produces a proof that the linear projection vanishes at the
corresponding F₂-vector. Given the F₂-vanishing proof, the bridge
reads off the corresponding Bool-falseness.

**Why this is mechanical (not enumerated):**

- N-1 reduces the 2-case Bool dispatch to a single F₂-Like
  invocation. No manual enumeration of `true`/`false`.
- N-2 reduces the 32-case Bool⁵ enumeration to componentwise
  application of N-1. No manual enumeration of the 32 codewords.
- N-3's `Reserved-Selector` is built by M-5 — no manual proof of
  linearity.
- N-4's `KernelCode` membership is definitional (the linear map
  applied to the vector equals 𝟎ⱽ).
- N-5's bridge proof is `cong (λ v → (lookup v 3 ≡ 𝟘) × (lookup v 4
  ≡ 𝟘))` through the N-1 per-bit bridges. ~10 lines max.

## Step 6 — Multi-angle reserve

If N-2's Angle A (five-tuple destructuring) is awkward for
downstream consumers (e.g., they want generic `Bool^k` ↔ `Vector k`),
fall back to:

- **Angle B — generic combinator**: introduce a `Bool-Tuple k` type
  (with conversions to Codeword for k=5) and the corresponding
  `Bool-Tuple-k ↔ Vector k` bridge. More reusable but adds a layer
  of representation conversion. Useful if M-10B/M-10C need similar
  bridges for different bit-widths.

- **Angle C — sigma-typed Reserved**: rather than a KernelCode, model
  Reserved-Structural as `Σ (Vector 5) (λ v → lookup v 3 ≡ 𝟘 × lookup
  v 4 ≡ 𝟘)`. Closer to the existing Codeword.agda predicate-style;
  loses the F₂-linear universal property. Reserved if KernelCode
  membership doesn't compute cleanly through to consumers.

introduce a third framing: **F₂-affine reading**, treating Codeword
as F₂⁵ with Reserved as a 3-dim affine subspace. This is the
"natural" mathematical framing but requires M-5.5 affine machinery
(deferred in parent plan).

## Pattern instance — 3+1 parity at n=5

N-3 (Reserved-Selector) and N-4 (Reserved-Structural) are the n=5
instance of the **3+1 parity universal pattern** (memory:
`project_3plus1_parity_universal`).

- **F₂⁵ split:** F₂⁵ = `⟨e₃, e₄⟩` (the V₄-coords plane, 2-dim) ⊕
  `⟨e₀, e₁, e₂⟩` (complement, 3-dim).
- **Reserved (1/4):** the V₄-zero coset = `⟨e₀, e₁, e₂⟩` itself =
  8 elements. KernelCode of N-3's projection.
- **Live (3/4, deferred to M-10B):** the 3 V₄-nonzero cosets =
  24 elements = the parity-complement.

The "high-two-bits projection" framing in N-3 is the V₄-coordinate
projection in disguise; the kernel (= Reserved) IS the codim-2
V₄-orthogonal subspace, Hodge-dual to the V₄-plane.

This makes M-10A part of the same orbit family as M-12 N-2
(V4-Nonzero, n=2 instance) and M-12 N-5 (OrbitKey, n=3 instance).
The generator is the 2-dim F₂-subspace W; no wrapper extraction.

## What this slice does NOT claim

To avoid confusion with the parent plan's M-10 description:

1. **NOT** `Reserved-Structural ≅ RM(1,3)`. RM(1,3) has 16 codewords;
   Reserved has 8. The parent plan's "Reserved (8) = RM(1, 3) image"
   is a cardinality mismatch and the deferred section already flags
   it. M-10A takes the correct signed-singletons reading
   (Axis × Sign = 4 × 2 = 8).
2. **NOT** that Live is F₂-linear. Live has 24 elements, not a
   power of 2; it's the complement of a linear subspace, not a
   subspace itself. Deferred to M-10B.
3. **NOT** replacing Codeword's existing Bool⁵ definition. M-10A
   ADDS a structural reading per the multi-reading-ambient
   discipline; the Bool⁵ form remains.
