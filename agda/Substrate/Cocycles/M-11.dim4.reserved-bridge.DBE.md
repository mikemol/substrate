# DBE: M-11.dim4.reserved-bridge — SelfDual ↔ Reserved validation

**Cross-reference:** parent plan at `agda/Substrate/Cocycles.DBE.md`;
M-11.dim4 (Λ²(F₂⁴) + Hodge ★ + 8-element SelfDual subspace);
Codeword.agda (32 = 24 + 8 ambient; Reserved = 8 codewords with
bit₃ = bit₄ = false). Memory: `project_3plus1_parity_universal`.

**The catalog conjecture (informally):** "8 reserved = signed singletons
= Hodge 1-form / 2-form layer." This slice tests whether the 8 self-dual
bivectors in Λ²(F₂⁴) and the 8 reserved codewords in Codeword.agda are
structurally equivalent via a meaningful F₂³ bijection.

## Step 1 — Halt and name the target

**In scope:**

- Helper lemma `apply-hodge-star-lookup`: lookup of `apply hodge-star ω`
  at index j equals lookup of ω at index `complement j`. This is the
  fundamental "Hodge ★ permutes lookup indices" fact that lets us
  reason about self-duality via per-index equality.
- Add `sd-closed-*ₛ` to SelfDual.agda (closure of self-duality under
  scalar multiplication) — small missing piece.
- The 8-element bijection: `SelfDual ≅ Vector 3` via the 3 free
  coefficients (one per fixed-point-free pair). Both forward
  (extract first 3 lookups) and backward (build symmetric vector)
  + the self-dual proof for the constructed vector.
- One round-trip (the trivial direction: backward-then-forward = refl).
- Capstone: document the Reserved ↔ Vector 3 ↔ SelfDual chain;
  Codeword.agda's existing `Reserved ↔ Axis × Bool` reading gives the
  Reserved-side F₂³ identification; this slice gives the SelfDual-side
  identification; together they validate the catalog conjecture at the
  cardinality + F₂³-structure level.

**Out of scope:**

- The other round-trip (forward-then-backward) — requires deriving
  lookup-equalities `lookup ω 3 ≡ lookup ω 2` etc. from `SelfDual-Pred ω`
  via apply-hodge-star-lookup. Documented but deferred unless trivial.
- Formal connection to `Codeword.agda`'s `Reserved ↔ Axis × Bool`
  bijection (would require M-10A foundations: Bool ↔ F₂, Codeword ↔
  Vector 5). Documented in docstring.
- Cardinality 8-as-formal-proof (would require finite-set enumeration
  machinery; the F₂³ structure makes 8 = 2³ obvious).

## Step 2 — Search for repeatable form

The bridge exploits a shared F₂³ structure:

| Side | Vector 3 parametrization | Cardinality |
|------|-------------------------|-------------|
| Reserved (Codeword.agda) | (bit₀, bit₁, bit₂) free; bit₃ = bit₄ = false | 2³ = 8 |
| SelfDual (M-11.dim4) | (lookup ω 0, lookup ω 1, lookup ω 2) free; ω self-dual | 2³ = 8 |

Both are 3-dim F₂-subspaces. The "bridge" is the trivial F₂³ ↔ F₂³
identity on Vector 3 coefficients. The non-trivial content is showing
each side IS Vector 3 (the 3-parameter family covers all 8 elements).

Per orbit-saturation: don't extract a "F₂³-Like-Subspace" wrapper;
both Reserved and SelfDual are concrete 3-parameter constructions.

## Step 3 — Name the costructures (shadows)

**N-1 — `apply-hodge-star-lookup`** (helper in HodgeStar.agda):
  ```
  apply-hodge-star-lookup : (ω : Bivector) (j : Fin 6) →
    lookup (apply hodge-star ω) j ≡ lookup ω (complement j)
  ```
  Proof via `apply-linear-from-images-lookup` + 6-case sum collapse
  (one per j). The sum collapses because each term has factor
  `lookup (basis (complement i)) j` = `𝟙 if complement i = j else 𝟘`
  = `𝟙 if i = complement j else 𝟘` (by complement-involution).

**N-2 — `sd-closed-*ₛ`** (helper in SelfDual.agda):
  ```
  sd-closed-*ₛ : (c : F₂) (ω : Bivector) → SelfDual-Pred ω →
    SelfDual-Pred (c *ₛ ω)
  ```
  Closure of self-duality under scalar multiplication. ~3 lines via
  preserves-*ₛ + cong.

**N-3 — `vector3-to-selfdual-Vec`**: the backward direction. Given
  v = (c₀, c₁, c₂), construct ω = (c₀, c₁, c₂, c₂, c₁, c₀) (the
  symmetric form matching the index-reversal involution).
  ```
  vector3-to-selfdual-Vec : Vector 3 → Bivector
  ```

**N-4 — `vector3-to-selfdual-Vec-sd`**: proof that the constructed
  ω is self-dual. Uses apply-hodge-star-lookup at each j: lookup
  (apply hodge-star ω) j = lookup ω (complement j); each pair
  (c₀↔c₀, c₁↔c₁, c₂↔c₂) closes by refl.

**N-5 — `selfdual-coefficients`**: the forward direction. Extract the
  3 free coefficients (lookup at 0, 1, 2) into a Vector 3. The
  SelfDual-Pred argument is unused but documents the precondition.

**N-6 — Round-trip (backward then forward)**:
  `selfdual-coefficients (vector3-to-selfdual-Vec v) sd ≡ v`. Trivial
  by refl on each of 3 components.

**N-7 — Capstone bridge identification** (docstring + minimal
  statement): the Reserved ↔ SelfDual structural correspondence via
  shared F₂³ parametrization, validating the catalog conjecture at
  the cardinality + F₂-vector-space-structure level.

## Step 5 — Entailment

**Entailment claim:** SelfDual (8 bivectors fixed by Hodge ★ in F₂⁴)
and Reserved (8 codewords with high-two-bits-zero in Codeword.agda's
Bool⁵ ambient) are STRUCTURALLY EQUIVALENT as 3-dim F₂-subspaces.
Both parametrize over Vector 3 in F₂³; the bridge is the trivial
Vector 3 ↔ Vector 3 identity at the parametrization level.

This validates the catalog's "8 reserved = signed singletons / Hodge
1-form" conjecture at the F₂-vector-space level. The deeper question
of whether the bridge respects additional structure (V₄ actions,
chirality semantics) is a follow-up — but the cardinality + linear-
algebra structure DOES match, which is the necessary first step.

## Step 6 — Multi-angle reserve

If `apply-hodge-star-lookup` proves too tedious (6 cases × ~15-line F₂
chains), fall back to:

- **Angle B — closure-based self-dual proof**: build
  `vector3-to-selfdual-via-gens v = c₀ *ₛ sd-pair-01-23 +ⱽ c₁ *ₛ
  sd-pair-02-13 +ⱽ c₂ *ₛ sd-pair-03-12`. Self-duality follows from
  `sd-closed-*ₛ` + `sd-closed-+ⱽ` + the existing sd-pair-*-self-dual
  proofs. No case analysis. But the round-trip is harder because the
  lookup structure of the generator form needs F₂ unfolding.

If both fail, fall back to:

- **Angle C — single-instance demonstration**: explicitly construct one
  Reserved codeword + one self-dual bivector + show they correspond.
  ~30 lines, no proofs of self-duality or round-trips. Document the
  general correspondence in prose. Validates the conjecture at one
  point rather than universally.
